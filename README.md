# Chronofond

Appli Android (Kotlin + Compose) : fait défiler des photos choisies (ou des mosaïques de 1 à 8 photos, avec le choix de la disposition : côte à côte, empilées, grille, mélange paysage/portrait…)
sur l'écran d'accueil et/ou l'écran de verrouillage, avec réglages séparés pour chaque écran.

## Build
1. Poussez ce dossier à la racine d'un dépôt GitHub (branche `main`).
2. Onglet Actions > "Build APK" (se lance au push, ou manuellement).
3. Téléchargez l'artefact `chronofond-apk` et installez l'APK.
